# Журнал решений по ГДД

Источник: [virus incremental GDD](https://docs.google.com/document/d/1zwlrlsBUA6YJIUunny5zhd4EC5HnOnUXRcNLR0Puqus/edit)
Вкладки: «Идея», «Мини концепт», «Механики», «ДОП. mvp i td», «Вкладка 5» (пустая).

## Принято

| # | Тема | Решение |
|---|------|---------|
| 1 | Кормление вируса | Drag-and-drop: игрок перетаскивает файлы и папки в вирус. |
| 1a | Момент поглощения | Файл съедается, когда игрок отпускает его над вирусом. Касание во время перетаскивания ничего не делает. |
| 1b | Промах | Файл, отпущенный мимо вируса, остаётся на месте. |
| 1c | Появление файлов | Как в ГДД: несколько файлов на старте, дальше по одному с интервалом, есть лимит на экране. |
| 1d | Зоны без спавна | Файлы не появляются под UI из списка `spawnBlockers` (сейчас счётчик MB и таймер) и под таскбаром. |
| 3a | Рост вируса | Вирус растёт после N съеденных файлов, порог растёт экспоненциально (`iconsPerGrowth`, `exponent` на `Virus`). |
| 4 | Навыки MVP | Скорость, Ползуны, Мышь. Мутации сняты, пока не переделаем. |
| 4a | Цена навыков | Временно за MB. Заменить, когда будет решена тема ресурсов. |
| 4b | Скорость | Файлы появляются на рабочем столе чаще. |
| 4c | Ползуны | Вместо притяжения: узел «Ползун» выпускает маленького вируса. Он сам ползёт к свободному файлу, садится и скачивает. Пока качает — белеет. Файл даёт MB как съеденный гличом. Дальше: «Быстрые лапки» (скорость), «Быстрая закачка», «Колония» (до 3 ползунов, не на один файл). |
| 4d | Мутации | Сняты с дерева, пока не переделаем. Комбо, цепная реакция, время за ПК и спутники не работают. |
| 4e | Мышь | Ветка «Цепкий курсор» → «Без рук». «Без рук» — разовая дорогая покупка: кормление наведением, без ЛКМ. |
| 4f | Сервер | 11-й ПК — сервер. Отдельного узла «Сетевой червь» нет. Сервер открывается, когда всё оставшееся дерево на максимуме. Иначе после 10-го ПК: «СЕРВЕР ЗАЩИЩЁН», ран кончается. Что происходит на открытом сервере — отдельно. |
| 6 | Глитч / Вирус | Это один и тот же персонаж. |
| 7 | Цикл игры | Как в «A Game About Feeding a Black Hole»: забег по таймеру в `Main`, по окончании — сцена `Skill Tree`, кнопка «Новый забег». Каждый забег начинается заново, MB и навыки сохраняются. |
| 7a | Дерево навыков | Отдельная сцена `Skill Tree`. Сначала видна только ветка скорости и серый тизер следующей. Каждые 3 купленных уровня открывают ещё одну ветку. Внутри ветки виден следующий шаг после купленного родителя. Уже показанные узлы запоминаются. Скрытые узлы и линии к ним не рисуются. Перетаскивание мышью, зум колёсиком, подсказка при наведении. |
| 7b | Сохранение | MB, уровни навыков и уже показанные узлы дерева пишутся в `PlayerPrefs` и живут между запусками. Полный сброс — кнопка «Начать заново» в концовке. |
| 7c | Загрузка сцен | Через `ViewManager`: сцена `ViewManager` загружается первой и подгружает `Main` / `Skill Tree` поверх себя. |
| 7d | Таймер | Короткая шкала внизу по центру: убывает, краснеет к концу, мигает в последние 3 с. Справа от неё текст `0:08`. |
| 7g | Начало игры | Первый ран сессии: на столе только «Новая папка». Двойной клик открывает окно с `glitch.exe`, двойной клик по нему — появляется глич, и только тогда стартуют таймер и спавн. Следующие раны начинаются сразу. |
| 7i | Концовка | Заражён сервер: перегрузка (вирус раздувается на весь экран, тряска, ошибки), синий экран смерти, выключение кинескопа, финальный экран «ВСЕ 11 КОМПЬЮТЕРОВ ЗАРАЖЕНЫ» со статистикой сессии. «Начать заново» — полный сброс прогресса, «Продолжить жрать» — в дерево. |
| 7h | Ощущение прогресса | Каждый съеденный файл: «+N MB» над вирусом, искры, кольцо, подпрыгивает счётчик MB. Золотые файлы стоят ×5, при поедании трясётся камера. В тултипе дерева видно «сейчас → после покупки». На экране конца рана: сравнение с прошлым раном, «НОВЫЙ РЕКОРД!», на кнопке «апгрейд» — сколько улучшений уже по карману. |
| 7e | Заражение компьютеров | В пределах одного рана: съел нужное число файлов, вирус раздувается и перескакивает на следующий ПК (рабочий стол и размер вируса сбрасываются, таймер не сбрасывается). Всего 11 ПК; заражены все 11 — ран кончается досрочно. |
| 7f | Конец рана | Экран в `Main` по макету: монитор «отъезжает», заражено ПК X/11, тотал MB за ран, файлов заражено, кликов сделано (все клики мышью), ГБ получено (MB / 1024). «апгрейд» ведёт в `Skill Tree`, «продолжить» сразу запускает новый ран. «Пауза/Настройки» открывает стартовое меню. |
| 8 | Таскбар | Всегда внизу экрана (44 px при 1080p) в стиле Windows XP: зелёная кнопка «пуск», задача `glitch.exe`, часы. Создаётся кодом (`Taskbar`, `DontDestroyOnLoad`), живёт во всех сценах. Файлы под ним не появляются, таймер и подсказки подняты над ним. |
| 8a | Стартовое меню | По «пуск» или Esc. Пункты: Продолжить, Настройки, Главное меню, Выйти из игры. Пока меню или настройки открыты, игра на паузе (`GamePause`: `timeScale = 0`, звук на паузе). Esc: из настроек — назад в меню, из меню — закрыть. Клик мимо меню закрывает его. |
| 8b | Настройки | Окно в стиле XP: общая громкость (ползунок с %), разрешение (dropdown), язык RU/EN, спецэффекты экрана (вкл/выкл: пост-обработка и глитч-текст), тряска экрана (вкл/выкл). Сохраняются в `PlayerPrefs`. |
| 8c | Главное меню | Пока тестовая сцена `Main Menu Test` с кнопкой «Назад» в сцену, из которой пришли. Возврат в `Main` начинает новый ран. Настоящее меню — позже. |
| 8d | Локализация | Вся игра на RU и EN (`Loc`, `LocalizedText`), язык меняется сразу, без перезапуска. |
| 9 | Монитор | Игра рисуется на модель `Assets/3D/old-monitor`: 2D-камера пишет картинку в текстуру стекла, 3D-камера показывает корпус. Стекло выпуклое, на нём сканлайны, виньетка, хроматика и мерцание. Клик по стеклу попадает в игру. |

## Текущие числа (подбираются в инспекторе)

| `DesktopIconManager` | Файлов на старте | 5 |
| `DesktopIconManager` | Максимум файлов на экране | 12 |
| `DesktopIconManager` | Базовый интервал появления | 0.9 с |
