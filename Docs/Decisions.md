# Журнал решений по ГДД

Источник: [virus incremental GDD](https://docs.google.com/document/d/1zwlrlsBUA6YJIUunny5zhd4EC5HnOnUXRcNLR0Puqus/edit)
Вкладки: «Идея», «Мини концепт», «Механики», «ДОП. mvp i td», «Вкладка 5» (пустая).

## Принято

| # | Тема | Решение |
|---|------|---------|
| 1 | Кормление вируса | Drag-and-drop: игрок перетаскивает файлы и папки в вирус. |
| 1a | Момент поглощения | Файл съедается, когда игрок отпускает его над вирусом. Касание во время перетаскивания ничего не делает. |
| 1b | Промах | Файл, отпущенный мимо вируса, остаётся на месте. |
| 1c | Появление файлов | Как в ГДД: несколько файлов на старте, дальше по одному с интервалом, есть лимит на экране. |
| 1d | Зоны без спавна | Файлы не появляются под панелью навыков (и под любым UI из списка `spawnBlockers`). |
| 3a | Рост вируса | Вирус увеличивается раз в N съеденных файлов. N задаётся в инспекторе (`iconsPerGrowth` на `Virus`). |
| 4 | Навыки MVP | Скорость, Автономность, Мутирование. |
| 4a | Цена навыков | Временно за MB (текущий счётчик). Заменить, когда будет решена тема ресурсов. |
| 4b | Скорость | Файлы появляются на рабочем столе чаще. |
| 4c | Автономность | Вирус притягивает файлы в радиусе вокруг себя, уровень увеличивает радиус. С высокого уровня вирус ещё и сам выбирает файлы по всему экрану и затягивает их. |
| 4d | Мутирование | Пока концепт: кнопка-заглушка «скоро», купить нельзя. |
| 6 | Глитч / Вирус | Это один и тот же персонаж. |

## Текущие числа (подбираются в инспекторе)

| Где | Параметр | Значение |
|-----|----------|----------|
| `DesktopIconManager` | Файлов на старте | 3 |
| `DesktopIconManager` | Максимум файлов на экране | 15 |
| `DesktopIconManager` | Базовый интервал появления | 3 с |
| `DesktopIconManager` | Ускорение за уровень Скорости | +25% к частоте |
| `SkillManager` | Скорость: цена / рост / макс. уровень | 5 MB / ×1.5 / 10 |
| `SkillManager` | Автономность: цена / рост / макс. уровень | 10 MB / ×1.6 / 10 |
| `VirusAttraction` | Радиус притяжения | 1.5 + 0.5 за уровень после первого |
| `VirusAttraction` | Скорость притяжения | 3 ед./с |
| `VirusAttraction` | Поедание по всему экрану | с 5 уровня, раз в 3 с, −0.4 с за уровень, минимум 0.5 с |

## Отложено (не трогать, пока не решено)

| # | Тема |
|---|------|
| 2 | Ресурсы и валюты (Data, Mass, MB) |
| 3 | Смена формы вируса и ступени Tier (частично решено в 3a: рост раз в N файлов) |
| 5 | Переход на новый ПК (сброс навыков или повышение их максимального уровня) |

## Ещё не обсуждалось

- Онбординг первых минут из вкладки «Механики»: подсказка «Перетащи файл в вирус», шкала «0 / 3 файла», Tier 1 → Tier 2.
- Шкала Corruption (прогресс заражения компьютера).
- Типы файлов и папок (например, `report.txt`), их разная ценность.
- Оформление рабочего стола в стиле Windows XP.
