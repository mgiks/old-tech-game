# Virus XP skill icons

Twenty-one 48×48 RGBA pixel-art symbols use the exact IDs and meanings supplied by the user. Each `icon_<id>.png` is independent and contains no baked skill label. The consistent dark XP hardware frame lets the symbols read as one set; green marks the virus, blue system hardware, gold files/energy, and red the medical or danger cues. Use localized Unity text for names and descriptions. `SkillIconDefinitions.json` maps each ID to a path and display label.
